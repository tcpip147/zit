# Diff Editor Quickstart

1. Run `cargo check -p zit`.
2. Open a project with a commit containing a text-file change.
3. Select the commit and a changed file in History.
4. Verify parsed additions/deletions, before/after numbers, hunk separators, and fixed gutter behavior.
5. Use the wheel and both scrollbar thumbs; verify synchronized vertical movement and code-only horizontal movement.
6. Select another changed file and verify the new diff starts at the top-left.
7. Run the widget and project contract tests when available.
