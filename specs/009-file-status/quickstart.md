# File Status Quickstart

1. Run `cargo check -p zit`.
2. Open a project with staged and unstaged working-tree changes.
3. Open File Status and verify the left staged/unstaged column, right DiffEditor column, and full-width commit footer.
4. Select files and verify the DiffEditor updates.
5. Enter a commit message and verify the Commit action remains visible.
6. Use Stage and Unstage and verify files move between lists.
7. Validate commit, refresh, empty, and error states.
